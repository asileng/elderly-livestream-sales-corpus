# 老年群体推销话语语料库

本语料库收集中文老年健康类推销话术，来源为公开直播与短视频，已完成录音转写与句级标注，共 5,008 句、162,915 字（含标点）。其中直播 2,350 句，短视频 2,658 句。

## 本仓库提供什么

仓库内只有说明与样例，不含全量数据。样例 200 句，A 路 70、B 路 60、短视频 70，两层标签齐全，字段与标注体系见 `sample/README.txt`。

全量 5,008 句可按研究用途申请获取，联系 `kodawbeamer@shisu.edu.cn`，说明单位、用途与使用期限。申请通过后提供 `corpus.csv`（5,008 行，六列），不提供音频、视频、原始链接与账号信息。

## 字段

每行一句，共六列。`id` 是句号，`L0001` 起为直播、`V0001` 起为短视频；`channel` 标 `A`、`B` 或 `V`，前两者为直播的两路信号，后者为短视频；`subcorpus` 标 `live` 或 `shortvideo`；`text` 是句子文本；`searle` 与 `p4g` 是两层标签。

## 标注

言语行为按 Searle（1979）分五类：断言、指令、承诺、表达、宣告，另设「其他」兜底。这一层是穷尽的，每句都有归属。

说服策略按 Wang 等（2019）在 Persuasion for Good 语料库中提出的十一类：逻辑诉求、情感诉求、可信度诉求、登门槛、自我示范、个人故事、购买信息、来源探询、任务探询、个人探询、非策略。这一层不穷尽，只覆盖带说服意图的句子。

每句两个标签，各取一个，先判言语行为再判说服策略。一句话里出现两个行为时取句末那个。

两人独立双盲标注 500 句，按 A 路、B 路、短视频三层分层抽取。言语行为 κ=0.74、观测一致率 85%；说服策略 κ=0.66、观测一致率 79%。十一类中「购买信息」与「来源探询」在语料中无实例。

## 注意

短视频部分包含少量口播 AI 生成文案的视频（如向 AI 提问后念读回答），以及繁简字混排的文本；分析真人自然话术时应予剔除。

语料按单声源处理，主播、助播与回应弹幕位于同一层。

音频不随语料提供，作者、账号、标题均未记录。

数字前后矛盾处保留原值并标 `〔?数〕`；未确认的专有名词掩码为 `［专名］`，不作猜测。
