# 老年群体推销话语语料库

本仓库收集中文老年健康类推销话语，供话语分析与反诈研究使用。语料分两个子库：直播带货与健康类短视频。两库用同一套切分和标注规范，可以分开用，也可以合起来用。

  * 直播带货
    * 微信视频号、抖音，2 场，246 分钟
    * 26 个分片，2,350 句
  * 健康类短视频
    * 抖音，109 条，286 分钟
    * 2,658 句

合计 5,008 句，162,915 字。

## 注意

语料按单声源处理：主播、助播与回应弹幕位于同一层，未作说话人区分。

直播子库的时间码精确到句。其中约 0.8% 的句子来自 30 秒整块的按比例切分，时间值为近似，做时长相关的分析时建议单列。

音频不随语料提供。作者、账号、标题均未记录。

文本里有两类标记是保留原样的结果，不是缺漏：数字前后矛盾处保留原值并标 `〔?数〕`；未能确认的专有名词掩码为 `［专名］`，不做猜测。

## 目录

  * `segments_all.csv` - 全部 5,008 句，九列，可直接用 Excel 或 pandas 打开
  * `corpus.jsonl` - 同上，多一列 `note`，记录判定说明
  * `glossary.csv` - 术语表 76 条，含品牌的确认状态与异体写法
  * `source_registry.csv` - 语料来源登记，来源已掩码
  * `shortvideo_manifest.csv` - 短视频清单，含时长与来源音频文件名
  * `sample_200.csv` - 200 句样本，直播与短视频各 100 句

`segments_all.csv` 的字段：

  * `seg_id` - 句号。`A005-S0012` 是直播，`V031-S0004` 是短视频
  * `subcorpus` - `live` 或 `shortvideo`
  * `channel` - `A`、`B` 为直播两路，`V` 为短视频
  * `start`、`end` - 相对 10 分钟分片起点的秒数，仅直播子库
  * `abs_start` - 绝对时间，仅直播子库
  * `text` - 句子文本
  * `searle` - 言语行为，六类
  * `p4g` - 说服策略，十一类

## 标注

言语行为用 Searle（1979）的五类：断言、指令、承诺、表达、宣告，另加「其他」兜底。这一层是穷尽的，每句都有归属。

说服策略用 Wang 等（2019）在 Persuasion for Good 语料库中提出的十一类：逻辑诉求、情感诉求、可信度诉求、登门槛、自我示范、个人故事、购买信息、来源探询、任务探询、个人探询、非策略。这一层不穷尽，只覆盖带说服意图的句子。

每句两个标签，各取一个，先判言语行为再判说服策略。一句话里出现两个行为时取句末那个。

P4G 原方案是为公益劝说设计的，没有给稀缺促销、购买指令、价格信息设类。本语料按原方案处理，这三类记为非策略，分析时用词项检索单独统计。

两人试标 20 句，言语行为一致 20/20，说服策略 19/20。全库 63 组重复话术的标签冲突经仲裁后为零。

## 用法

```python
import pandas as pd

df = pd.read_csv("segments_all.csv")
df.groupby(["subcorpus", "searle"]).size()
df[df.p4g != "non_strategy"]
```
