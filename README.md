# 老年群体推销话语语料库

中文老年健康类推销话语的转写与句级标注语料，分直播带货与健康类短视频两个子库。两库用同一套切分和标注规范。

  * 直播带货
    * 微信视频号、抖音，2 场，246.2 分钟
    * 26 个分片，2,350 句
  * 健康类短视频
    * 抖音，109 条，286.5 分钟
    * 2,658 句

合计 5,008 句，162,915 字。

## 本仓库提供什么

本仓库只放说明与样例，不放全量数据。

  * `sample/sample_200.csv` —— 200 句样例，直播与短视频各 100 句，两层标签齐全
  * `sample/README.txt` —— 样例的字段与标注体系说明
  * `data/shortvideo_manifest.csv` —— 短视频的技术字段（句号、时长、字数）

全量 5,008 句不在仓库内，可按研究用途申请获取，说明用途后提供。

## 字段

样例表与全量表结构一致，每行一句：

  * `seg_id` —— 句号。`A005-S0012` 是直播，`V031-S0004` 是短视频
  * `subcorpus` —— `live` 或 `shortvideo`
  * `text` —— 句子文本
  * `searle` —— 言语行为
  * `p4g` —— 说服策略
  * `note` —— 判定说明

全量表另有 `channel`、`start`、`end`、`abs_start` 四列，用于直播子库的时间对齐。

## 标注

言语行为采用 Searle（1979）的五类：断言、指令、承诺、表达、宣告，另设「其他」兜底。该层穷尽，每句都有归属。

说服策略采用 Wang 等（2019）在 Persuasion for Good 语料库中提出的十一类：逻辑诉求、情感诉求、可信度诉求、登门槛、自我示范、个人故事、购买信息、来源探询、任务探询、个人探询、非策略。该层不穷尽，只覆盖带说服意图的句子。

每句两个标签，各取一个，先判言语行为再判说服策略。一句出现两个行为时取句末那个。

两人试标 20 句，言语行为一致 20/20，说服策略 19/20。全库 63 组重复话术的标签冲突经仲裁后为零。

## 注意

语料按单声源处理：主播、助播与回应弹幕位于同一层。

直播子库时间码精确到句，其中约 0.8% 的句子为整块按比例切分所得，时间值为近似。

音频不随语料提供。作者、账号、标题均未记录。

文本里有两类标记是保留原样的结果：数字前后矛盾处保留原值并标 `〔?数〕`；未确认的专有名词掩码为 `［专名］`，不作猜测。
