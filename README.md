# 老年群体推销话语语料库

中文老年健康类推销话术的录音转写与句级标注，共 5,008 句。

  * 直播带货
    * 微信视频号、抖音，2 场
    * 2,350 句
  * 健康类短视频
    * 抖音，109 条
    * 2,658 句

合计 5,008 句，162,915 字（含标点）。

## 本仓库提供什么

本仓库只放说明与样例，不放全量数据。

  * `sample/sample_200.csv` —— 200 句样例，直播 130 句（A 路 70、B 路 60）、短视频 70 句，两层标签齐全
  * `sample/README.txt` —— 样例的字段与标注体系说明

全量 5,008 句不在仓库内，可按研究用途申请获取。

## 字段

样例与全量表结构相同，每行一句：

  * `id` —— 句号。`L0001` 为直播，`V0001` 为短视频
  * `subcorpus` —— `live` 或 `shortvideo`
  * `text` —— 句子文本
  * `searle` —— 言语行为
  * `p4g` —— 说服策略
  * `note` —— 判定说明

## 标注

言语行为采用 Searle（1979）的五类：断言、指令、承诺、表达、宣告，另设「其他」兜底。该层穷尽，每句都有归属。

说服策略采用 Wang 等（2019）在 Persuasion for Good 语料库中提出的十一类：逻辑诉求、情感诉求、可信度诉求、登门槛、自我示范、个人故事、购买信息、来源探询、任务探询、个人探询、非策略。该层不穷尽，只覆盖带说服意图的句子。

每句两个标签，各取一个，先判言语行为再判说服策略。一句出现两个行为时取句末那个。

两人独立双盲标注 500 句（按直播 A、直播 B、短视频三层分层抽取），言语行为 κ=0.74、观测一致率 85%；说服策略 κ=0.66、观测一致率 79%。十一类中有两类（购买信息、来源探询）在语料中无实例。

## 注意

语料按单声源处理：主播、助播与回应弹幕位于同一层。

音频不随语料提供。作者、账号、标题均未记录。

文本里有两类标记是保留原样的结果：数字前后矛盾处保留原值并标 `〔?数〕`；未确认的专有名词掩码为 `［专名］`，不作猜测。
